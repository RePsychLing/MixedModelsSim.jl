MixedModelsSim.jl

MixedModelsSim.jl provides utilities for designing and power-analysing experiments with mixed-effects models. It is a companion to MixedModels.jl.

What this package does

  • Generate crossed experimental designs — subjects × items × conditions with arbitrary combinations of between-subject, between-item, and within-both factors (simdat_crossed)
  • Specify random-effects covariance structure — create the lower Cholesky factor of a covariance matrix from standard deviations and optional correlations (create_re), and convert it to the θ parameter vector MixedModels.jl expects (createθ)
  • Run power analyses — simulate data via parametricbootstrap from MixedModels.jl and summarise the results as a power table (power_table)

Installation

MixedModelsSim.jl is registered in the Julia package registry:

using Pkg
Pkg.add("MixedModelsSim")
